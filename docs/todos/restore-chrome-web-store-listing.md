# Restore the removed Chrome Web Store listing

Google removed the previously published Cloudstash extension listing. The
reason has not yet been established.

## Completion

- Read and record Google's removal reason from the publisher account or notice.
- Resolve the specific policy, metadata, permission, or packaging issue without
  guessing at the cause.
- Resubmit the extension and confirm the public listing is available again.
- Verify the restored copy describes opening the popup and choosing Save; do
  not claim an unavailable global shortcut or automatic toolbar capture.
- Update the production install URL if Google assigns a different listing ID.

This is primarily a maintainer operation because it requires Chrome Web Store
publisher access. Any required repository change should be split into a
specific implementation task once the removal reason is known.
